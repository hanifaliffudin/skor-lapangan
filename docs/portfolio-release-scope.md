# Portfolio release scope

## Current decision

Skor Lapangan is maintained as a portfolio project and an informal mabar scorekeeper. It is non-commercial and intended for the owner and invited friends. This scope does not claim to be a public service, an official referee tool, or a federation product.

## Included

- Local scorekeeping for the supported sports and formats.
- Offline Match Continuity on the controlling device.
- Private Live Viewer links shared directly with friends.
- Club Session use with nicknames and only the data needed for a session.

## Kept out of the private release scope

- Public Community Rules publishing and moderation.
- Public account-history rollout and general user support promises.
- Payments or subscriptions.
- Public discovery, public rosters, or public player rankings.
- Analytics and Google Tag Manager. Both are disabled by default.

The account and Community Rules code may remain available in Preview for development, but it should not be advertised as part of this private project release.

## Use guidance

- Use nicknames instead of full names where possible.
- Do not enter passwords, identity numbers, payment details, health information, or other sensitive data.
- Treat Live Viewer URLs as private links. Share them only with the people who should see the score.
- Delete old mabar data from the connected environment when it is no longer useful.
- Keep the project non-commercial unless the owner deliberately chooses a new release scope.

## Scope expansion trigger

Revisit the full legal and owner release gate before opening the service to the public, enabling Google account history, collecting data from unknown users, publishing Community Rules, adding analytics, or charging money.
