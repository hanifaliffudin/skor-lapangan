## Service providers

- Vercel hosts the web application when deployed there.
- Google Tag Manager is not loaded by the portfolio build. If it is enabled later, the operator must review its active tags and document any additional providers and data collection before publishing an updated notice.
- Vercel Web Analytics may collect anonymous, aggregated usage data when enabled for the project. It does not use cookies; this app removes query strings and redacts identifiers from page paths before events are sent. Vercel documents the data fields and visitor-hash lifecycle in its [privacy documentation](https://vercel.com/docs/analytics/privacy-policy). Its current documentation lists 50,000 included events for Hobby and says collection pauses after a three-day grace period when the limit is exceeded; Vercel says collection can resume after a seven-day wait or an upgrade. Check the [current limits and pricing](https://vercel.com/docs/analytics/limits-and-pricing) before publication.
- Supabase provides authentication, database storage, and Live Viewer access.
- Enabled OAuth providers provide authentication for users who choose account sign-in. Provider client secrets remain in Supabase Auth configuration and are not sent to the browser. The final notice must list the providers enabled in the deployed environment.
- hCaptcha may process a guest sign-in challenge if CAPTCHA protection is enabled. CAPTCHA is initially disabled; Supabase Auth IP-based rate limits and database action limits are used first. Enable CAPTCHA if abuse justifies the extra challenge.

This repository does not specify provider regions, provider log retention, or a final list of operational contacts. The operator must complete those details from the deployed project settings.

## User controls

- Guests can stop using the app and clear the site's browser data to remove local match data. This does not remove a server guest record before its expiry.
- Owners can revoke a Live Viewer link. A viewer may already have copied or recorded information that was visible before revocation.
- Authenticated users can open `/account` and permanently delete the account. The server-only deletion function removes owned matches, events, reports, Community Rules data if present, viewer capabilities tied to those matches, Club Sessions and their child records through account deletion cascade, and the Supabase Auth user; the browser also clears local match journals. A failed deletion should be retried from the account page while the session is still available.
- For privacy questions or a failed deletion, contact `[PRIVACY CONTACT EMAIL]`. The owner must confirm the final contact and retention wording before publication.

## Security and release notes

The browser uses Supabase's publishable key. The service-role key and any hCaptcha secret must remain in trusted server or dashboard configuration, never in the web bundle or repository.
